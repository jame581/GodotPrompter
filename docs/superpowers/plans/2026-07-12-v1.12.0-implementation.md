**Goal:** Ship v1.12.0 — trim the 9 over-budget skills, make the 16 KB token budget a CI-failing validator error, and add three third-party addon skills (`popochiu`, `dialogue-manager`, `phantom-camera`), growing the library 51 → 54 skills.

**Tech Stack:** Markdown skills (SKILL.md + references/), Node validator (`scripts/validate-skills.mjs`), GDScript + C# examples targeting Godot 4.3+ repo-wide.

## Global Constraints

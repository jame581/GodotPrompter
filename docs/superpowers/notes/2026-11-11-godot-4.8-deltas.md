# Godot 4.8 Deltas — Per-Skill Inventory (4.8-beta3)

Working document for the v1.17.0 4.8 pass (plan Phase C, Task C2). Each row pairs a Godot 4.8 deprecation, behavior change, stale-text fix or new feature with the skill that should carry it, a source at the pinned engine commit, and the build it was checked on. Phase D applies the rows; no skill was edited in this task.

**4.8 is not stable yet.** Every row was checked on **4.8-beta3**. Once `4.8-stable` is tagged, every row Phase D applies must be re-checked against that tag (timing gate). Rows marked *draft guide* rest partly on the unmerged migration guide and must be re-read when it lands.

## Research sources

- **Engine:** `godotengine/godot` at **`c51ff06e8836a70ea905701c081bf94124dcd6ce`**, the commit the `4.8-beta3` build was made from (`godotengine/godot-builds` release `4.8-beta3`, published 2026-11-09, release notes "Built from commit c51ff06e…"; the binary reports `4.8.beta3.official.c51ff06e8`). Baseline: tag `4.7.2-stable` (`ed1daf0bf001`). Citations below write the beta3 commit as **`b3:`** and 4.7.2 as **`472:`**, followed by `path:line`.
- **Class-reference diff:** `doc/classes/`, `modules/*/doc_classes/` and `platform/*/doc_classes/` parsed at both refs and compared member by member (methods with signatures, members with defaults, signals, constants, theme items, `deprecated=` and `experimental=` flags). Result: 34 new classes, 44 new deprecations, 14 removals, 21 signature/default changes, 396 additions. The TileMap classes moved from `doc/classes/` to `modules/tilemap/doc_classes/`, and `RegEx`/`RegExMatch` moved from `modules/regex/` to `doc/classes/` — both are moves with no API change.
- **Migration guide:** `upgrading_to_godot_4.8.rst` is **not on godot-docs `master` yet** (checked `master` @ `efe557b0`, 2026-11-10). It exists as draft PR godotengine/godot-docs#12421 ("Add 'Upgrading from Godot 4.7 to Godot 4.8' page"), read at head `089a0357fa41`. Cited as **`mg48:line`**. Every row that uses it was also checked against engine source or the class reference.
- **Release pages:** https://godotengine.org/article/dev-snapshot-godot-4-8-beta-3/ and the interactive changelog (`#4.8-beta3`) — used to find candidates only, never as a row's sole source (rule from `2026-10-11-godot-4.7-callout-audit.md`).
- **Runtime checks:** the 4.8-beta3 Linux editor run headless — the `addon-development` cross-version dock scaffold (GDScript) as an enabled plugin, the `gdscript-patterns` inner-class override example, and a `ClassDB`/`ProjectSettings` probe of every new API named in the rows.
- **Addons:** LimboAI #477 and Phantom Camera #694 re-read on 2026-11-11; latest tags still LimboAI `v1.8.1` and Phantom Camera `v0.11.0.4`.

# Godot 4.7 Deltas — Per-Skill Inventory

Working document for the v1.11.0 alignment pass. Each row pairs a Godot 4.7 feature, behavior change, or stale-text fix with the skill(s) that should carry it, plus a verified source. Rows without a verified source are dropped.

## Research sources

- Engine changelog: `D:/Godot/godot/CHANGELOG.md` § "4.7 - 2026-06-18" (PR links)
- Migration guide: `D:/Godot/godot-docs/tutorials/migrating/upgrading_to_godot_4.7.rst`
- Class reference: `D:/Godot/godot-docs/classes/class_*.rst` (docs clone master, includes 4.7 API)
- Release page (for citations in skills): https://godotengine.org/releases/4.7/

**Verification rule:** a row enters this table only after its feature is confirmed in the class reference `.rst` or the migration guide (changelog PR link alone is acceptable for editor/tooling items with no class-reference surface). Kind is one of: `api` (new API section), `warn` (behavior-change warning), `fix` (stale-text fix).

Repo-wide minimum stays **Godot 4.3+**; every applied row is annotated `(Godot 4.7+)` or as a `Changed in Godot 4.7` warning.

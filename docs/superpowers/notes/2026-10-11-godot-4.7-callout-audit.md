# Godot 4.7 callout audit — 2026-10-11

Every `> ⚠️ **Changed in Godot 4.7:**` callout in `skills/` (32 in 21 files) was checked against
primary sources: the 4.6 and 4.7 migration guides, class-reference XML and engine source compared
across the `4.5`, `4.6` and `4.7` branches and release tags, the cited pull requests, the GodotSharp
4.6.0 / 4.7.2 assemblies, and scripts run headless on Godot 4.6.3 and 4.7.2.

**22 were correct. 10 were corrected.**

| Callout | Was | Is |
|---|---|---|
| `3d-essentials` fog (and `references/fog-recipes.md`) | blending "changed in 4.7" | changed in 4.6 (GH-112494); 4.7 added `use_legacy_blending` (GH-119414), also on the 4.6 branch |
| `3d-essentials` `roughness_layers` | default 7 → 8 in 4.7 | 8 in 4.5, 7 only in 4.6.0–4.6.1, 8 again from 4.6.2 (GH-116154) |
| `animation-system` `LookAtModifier3D.relative` | `true` → `false` in 4.7 | `true` only in 4.6.0; backported to 4.6.1 |
| `particles-vfx` subemitter velocity | "reworked", effects may look different | no change from 4.6: GH-118062 fixed a 4.7-dev regression before stable. Now a plain note |
| `gdextension` text servers | custom text servers no longer a GDExtension use case | only the built-in text servers' GDExtension build scripts were removed; `TextServerExtension` is unaffected |
| `mobile-development` OBB | migrate to Play Asset Delivery "or PCK patching" | App Bundles with Play Asset Delivery, or the separate Godot OBB plugin |
| `assets-pipeline` font `hinting` | rendering can change after upgrading | already-imported fonts keep the value stored in `.import`; only new imports get the new default |
| `csharp-godot` `ImageUpdateMask` | `UpdateWidthInPercent` → `UpdateWidthUnit` | C# strips the prefix: `WidthInPercent` → `WidthUnit` |
| `gdextension` `object_cast_to` | "godot-cpp, gdext" handle it | only godot-cpp is named upstream |
| `export-pipeline` `runnable=` | tracked "separately" | a `[runnable_presets]` section in the same `export_presets.cfg` |

Three of the ten are version errors of the same kind: a 4.7 migration-guide entry for something
that had already changed, or been backported, in a 4.6 release. The 4.7 guide lists a change when
4.7.0 differs from 4.6.0, not when it differs from the latest 4.6 patch — check the patch tags.

`2026-07-05-godot-4.7-deltas.md` predates this audit and still carries the original wording.

## Example checks

**C#.** Every `csharp` block (494) was compiled against `Godot.NET.Sdk` 4.7.2. Blocks that define
a type were compiled as written; fragments were wrapped in a class or method; unknown user types
were stubbed so the compiler reaches method bodies (it skips them while declaration errors
remain — a first pass that did not stub checked declarations only). 401 blocks were body-checked;
93 could not be (addon types, signals or exports that take user types, pseudo-code). A review later found one
block the pass had held back and not reported (`multiplayer-basics`, a `Node` using
`GlobalPosition`), so "compiled" means every block the harness could build, not every block.

**GDScript.** Every `gdscript` block (656) was parsed with Godot 4.7.2 via `GDScript.reload()`:
463 script-like blocks as written, 193 fragments wrapped in a function. Most remaining errors are
context the snippet omits (no `extends`, helpers and autoloads defined elsewhere), so only
engine-level errors were acted on: unknown members and constants on engine classes, override
signatures, annotation placement.

## Godot 4.4 / 4.5 / 4.6 statements

Every statement in `skills/` that ties a feature to 4.4, 4.5 or 4.6 was then checked the same way
(installed 4.7.2 via `ClassDB`, class reference and source compared across the 4.3 to 4.7 release
tags, GodotSharp 4.7.2, shaders compiled on the Compatibility renderer). Corrected:

| Skill | Was | Is |
|---|---|---|

| `localization` editor preview | "Preview Language" under Project Settings | **View → Preview Translation** in the 2D editor |
| `localization` CSV plurals (4.6) | `?pluralrule` column, both forms in one cell, "3+ plural forms need PO" | `?plural` column plus continuation rows; `?pluralrule` is an optional row; any number of forms works |
| `gdscript-patterns` abstract classes | abstract methods allowed without a class-level `@abstract`; instantiation fails "at runtime" | the class must be `@abstract`; `.new()` is rejected at parse time, a dynamic `load().new()` is not |
| `gdscript-advanced` | static vars "4.4+"; typed dictionaries "skip the Variant unbox" | static vars since 4.1; typed dictionaries validate on write, values are still Variant |
| `animation-system` LookAt | `symmetry_limitation = deg_to_rad(70)` | it is a bool; the angle is `primary_limit_angle` |

## Review follow-up

A code review of the branch found corrections that stopped at the file where they were made. Fixed:
the Shader Baker description in `shader-basics` (it still promised stutter-free rendering), the IK
solver summary in `agents/godot-animator.md`, Vision Pro listed as an OpenXR target in
`xr-development`, a 3D checklist item still dating the fog change to 4.7, and `csharp-signals`
prescribing a connect/disconnect pairing its own examples did not use. When a claim is corrected,
grep `skills/`, `agents/` and `.codex/` for its key nouns before calling it done.
